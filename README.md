# رفيق AI

مساعد ذكاء اصطناعي بواجهة عربية متجاوبة، يوفّر محادثات محفوظة محليًا وإمكانية رفع ملفات PDF وDOCX وTXT وMarkdown للسؤال عن محتواها.

## التشغيل محليًا

1. ثبّت Node.js 18.17 أو أحدث.
2. ثبّت الاعتماديات: `npm install`.
3. انسخ `.env.example` إلى `.env.local` وأضف مفتاح مزوّد متوافق مع واجهة OpenAI.
4. شغّل `npm run dev` وافتح `http://localhost:3000`.

```env
OPENAI_API_KEY=your-secret-key
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_MODEL=gpt-4o-mini
```

المفتاح يُستخدم على الخادم فقط ولا يُرسل إلى المتصفح. يمكن تغيير عنوان الواجهة والنموذج عبر متغيرات البيئة.

## الميزات

- واجهة RTL عربية متجاوبة.
- محادثات متعددة محفوظة في متصفح المستخدم.
- اقتراحات بداية للمحادثة.
- رفع مستندات PDF وDOCX وTXT وMarkdown (حد أقصى 5 ميغابايت) واستخدام نصها كسياق للمحادثة.
- واجهة API متوافقة مع مزودي النماذج الذين يدعمون `/chat/completions`.

## ملاحظات النسخة الأولية

- لا يوجد تسجيل دخول أو مزامنة سحابية بعد؛ المحادثات محفوظة في `localStorage` على الجهاز الحالي.
- أضف مصادقة، تحديد معدل الطلبات، وسياسة احتفاظ بالملفات قبل إتاحة الخدمة للعامة.
- محتوى الملف يُرسل إلى مزوّد الذكاء الاصطناعي مع الطلب، لذلك ينبغي توضيح ذلك للمستخدمين.
